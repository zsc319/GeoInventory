# 地数镜 · 本地化桌面端

这是与网页端并列的原生 Windows 桌面版本：使用 Python + PySide6 构建真实软件窗口，不会启动浏览器，也不需要监听本地网页端口。

## 当前可用功能

- 打开已有 `.nvt` 分析工区，直接读取其中的 `inventory.sqlite` 与 `project_snapshot.json`；不复制原始数据。
- 原生项目驾驶舱：文件、统一井、坐标井、LAS/DEV 覆盖等摘要。
- 原生“井与井名”：搜索、资料来源、二维井位、单井 DEV 轨迹、井点大小、缩放和平移。
- 原生资料数据库：按资料类型浏览完整目录索引，并可在资源管理器中定位源文件。
- 原生曲线、层位、生产动态摘要页：复用现有分析数据库，作为后续逐页迁移的落点。
- 深/浅主题、分辨率自适应布局；窗口尺寸与停靠区状态保存在本机设置中。

## 运行

在此目录双击 [启动桌面端.ps1](启动桌面端.ps1)。脚本会优先使用 PySide6 高级窗口；未安装时自动使用 Python 内置 Tk 原生窗口，不会启动浏览器。

也可以在终端运行：

```powershell
python -m pip install -r requirements.txt
python tk_desktop.py
```

首次打开后，点击“打开工区”并选择已有 `.nvt` 文件夹。未选择工区时，程序会尝试读取上一级项目的 `data/` 目录。

## 发行路径

桌面端不会与网页端混装。后续在本目录运行 `packaging\build_desktop.ps1` 将生成 `dist\地数镜桌面版`；若电脑安装 Inno Setup，则会继续生成可直接交付同事的安装程序。当前发行配置使用内置 Tk 原生窗口，因此同事安装后不需要额外安装 Qt。

Access/OFM `.mdb` 的读取仍依赖与程序位数一致的 Microsoft Access Database Engine。
