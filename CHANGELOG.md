# Changelog / 更新记录

## 0.6.1 — 2026-09-14

First public source-available evaluation release / 首次公开的源代码可见评估版本。

- Added bilingual project overview, installation, scope, limitations, roadmap, and citation guidance.
- Added source-available commercial license, authorship, trademark, institutional, data, and third-party notices.
- Embedded canonical author and legal identity in the web UI, API, desktop clients, and Windows executable metadata.
- Excluded local workspaces, databases, logs, scan snapshots, build outputs, and real project paths from version control.
- Verified the source release with the complete automated test suite.

- 增加中英文项目介绍、安装说明、功能边界、扩展方向与引用指南。
- 增加源代码可见商业许可证，以及作者、商标、单位、数据和第三方依赖声明。
- 在网页界面、身份接口、桌面端和 Windows 可执行文件属性中固化作者与法律声明。
- 从版本控制中排除本地工区、数据库、日志、扫描快照、构建产物和真实项目路径。
- 使用完整自动化测试验证首发源代码。
