地数镜 GeoInventory 0.7.0｜Windows x64 评估版（2026-09-28）

1. 将整个发行包解压到本机磁盘，不要只复制 GeoInventory.exe。
2. 双击“启动地数镜.bat”。稍候数秒，默认浏览器会打开 http://127.0.0.1:5178/。
3. 首次使用可在项目中心扫描资料目录，或打开已有的 .nvt 工区文件夹。
4. 停止软件：关闭“地数镜 GeoInventory”命令窗口，或双击“关闭地数镜.bat”。

本次发布
- 工区支持盘符和资料目录变更后的路径预览、核验与批量更新。
- 新增地震剖面预览、地质表面质量检查与多表面对比。
- 增加储量参数分析、生产动态校正与聚类分析等工作流程。
- 发布页同时提供 SHA-256 校验值，用于核对官方构建产物。

重要说明
- 软件只监听本机 127.0.0.1，不会主动把资料上传到网络。
- 发行包已内置 Python 运行环境；同事电脑无需另行安装 Python。请完整保留解压后的目录结构。
- 原始资料只读；分析索引和人工分类保存在 .nvt 工区中。
- 读取 OFM .mdb/.accdb 前，电脑必须安装与本软件位数一致的 64 位 Microsoft Access Database Engine。
- Windows SmartScreen 若提示“未知发布者”，请先核对文件来源；当前内部测试包尚未进行商业代码签名。
- 详细操作、数据口径和故障排查请查看《地数镜 GeoInventory 使用说明.docx》。
